# Farm-Spiel 0.1.0 – Level 1–10 Visual Build

Diese Version ersetzt die primitive Testwelt durch die **hochwertige Tal-/Farmwelt aus der festgelegten visuellen Referenz**.

## Enthalten

- Hochformat-Spielwelt mit Bergwerk, Wald, Sägewerk, Mühle, Hof, Dorf, Hafen und Leuchtturm
- freie 1-Finger-Kamera und stufenloser 2-Finger-Zoom
- scharfes Master-World-Artwork als visuelle Basis
- interaktive Weltobjekte und Hotspots getrennt von der Grafik
- Level-1–10-Missionskette
- Schrott-LKW, Postauto, Tieflader, Handwerker- und Tiertransporter
- Traktor-Aussaat und Mähdrescher-Ernte
- Feldzustände und 4-Minuten-Weizenwachstum
- Silo / Scheune / Werkstatt / Baustellen
- Mühle: Weizen → Mehl
- Hühner → Eier
- Kühe → Milch
- Bäcker-Aufträge
- Autosave + Backup + Offline-Fortschritt
- Tag/Nacht, Regen, Nebel, dezente Wolken und gelegentliche Vögel
- DEV-Modus mit Zeit, Wetter, Geld, XP und Debug-Hitboxen

## Grafikaufbau

Die ferne Talwelt nutzt in 0.1.0 ein hochauflösendes Master-World-Artwork, damit die sichtbare Qualität sofort der vereinbarten Vorlage entspricht. Gameplay-Zustände (Feld, Tiere, Fahrzeuge, Baustellen, Icons und Effekte) werden separat darüber gerendert und bleiben interaktiv. Dadurch ist die Version spielbar, während spätere Builds einzelne Weltbereiche weiter in modulare Assets aufteilen können.
