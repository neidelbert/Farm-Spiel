# Arbeitsablauf
ChatGPT oder Lukas erstellt bzw. genehmigt ein Ticket.
Perplexity bearbeitet ausschließlich Tickets mit Status:
READY
Während der Bearbeitung:
IN_PROGRESS
Nach Abschluss:
READY_FOR_REVIEW
Nach Prüfung:
APPROVED
oder:
CHANGES_REQUESTED
Kein nächstes Ticket automatisch starten.
