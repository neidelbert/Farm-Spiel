# Visual Reference

Master style: colorful, high-detail, cozy 2.5D/isometric mobile farming valley.

Map reading order:
1. mountain + mine
2. forest + sawmill + mill
3. central farm with silo/barn/workshop/fields/animals
4. village + church + bakery + market
5. harbor + fishery + lighthouse + sea

Visible humans/NPCs are intentionally omitted. Only occasional birds and light translucent clouds are used as ambient sky motion.
