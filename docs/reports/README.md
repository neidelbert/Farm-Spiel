# Farm-Spiel Development Reports
Dieser Ordner enthält Abschlussberichte zu Entwicklungstickets.
Namensschema:
`FS-XXX_REPORT.md`
Ein Report enthält mindestens:
- Ticket
- Status
- Ausgangs-SHA
- Ergebnis-SHA
- Commit
- geänderte Dateien
- neue Dateien
- durchgeführte Tests
- NOT TESTED Punkte
- gefundene Probleme
- Risiken
- bewusst nicht umgesetzte Funktionen
Ein Report ersetzt kein Code Review.
Nach Erstellung wartet das Ticket auf Prüfung.
